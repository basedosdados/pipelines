### Validation against 2024 (eleição 619, 12,170 zone files)

Compared with the official `detalhe_votacao_munzona_2024` /
`votacao_partido_munzona_2024` on the columns the builders read:

- detalhe: 12,207 official rows all matched by key; 99.7% exact on every
  value column, including `QT_SECOES_AGREGADAS` (derived from the polling-place
  file — 9 mismatches). The 37 rows that differ are all *prefeito* in
  municipalities whose 2024 result was later re-totalled or annulled (e.g.
  Oiapoque, supplementary election 12/04/2026): the API serves the current
  totals, the CDN file an earlier state. Not a mapping error.
- partido: 80,009 of 80,056 official rows matched; 96 value mismatches, all
  explained by the official file listing some parties twice (a zero row plus
  the real one) or by the same re-totalled municipalities.

Field mapping: aptos=`e.te`, secoes=`s.ts`, comparecimento=`e.c`,
abstencoes=`e.a`, votos validos=`v.vv`, nominais=`v.vnom`, legenda=`v.vl`,
brancos=`v.vb`, nulos=`v.tvn`; party nominais=`par.tvtn`, legenda=`par.tvtl`.
